Connect an agent

Agents connect to Nexus over MCP with their own token. Add the agent on the Agents page to get one.

Server

{{ mcp_url }}

Transport: streamable HTTP. Send the token as Authorization: Bearer <agent token>.

Claude Code

claude mcp add --transport http nexus {{ mcp_url }} --header "Authorization: Bearer <agent token>"

Claude Desktop

Save stdio-bridge.py, then add this to claude_desktop_config.json:

{
  "mcpServers": {
    "nexus": {
      "command": "python3",
      "args": ["/path/to/stdio-bridge.py", "{{ mcp_url }}", "<agent token>"]
    }
  }
}
